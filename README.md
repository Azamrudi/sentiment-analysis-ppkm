# Sentiment Analysis Twitter PPKM

Project ini melakukan analisis sentimen masyarakat terhadap kebijakan PPKM menggunakan data Twitter dan algoritma Naive Bayes.

## Tahapan Project
1. Data Collection
2. Text Preprocessing
3. TF-IDF Vectorization
4. Naive Bayes Classification
5. Evaluation
6. Visualization (WordCloud, Pie Chart, Bar Chart)

## Accuracy Model
Accuracy: 0.81

- Pandas
- Numpy
- Scikit-learn
- NLTK
- Sastrawi

- Matplotlib
